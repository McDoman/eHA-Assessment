# eHA-Assessment
    
Welcome to the eHealth Africa Technical Assessment Repository. This repository is organized into four main parts corresponding to the assessment structure.

## Repository Structure

- **[Part1 Q1 Campaign Tracking](./Part1_Q1_Campaign_Tracking/)**: Scripts for settlement visitation pipelines, tracking coverage, and QGIS hotspot analysis.
- **[Part1 Q2 Facility Access](./Part1_Q2_Facility_Access/)**: Spatial database pipelines, crosswalk normalization, and geographic access level assessments.
- **[Part2 Q3 ODK Form Design](./Part2_Q3_ODK_Form_Design/)**: Automation scripts for ODK form design, checkdigit validation, data quality checks, and document building.
- **[Part2 Q4 Coverage Survey](./Part2_Q4_Coverage_Survey/)**: Weighting, spatial analysis, and PDF report generation for coverage surveys.

*Note: All heavy datasets and non-essential documentation have been excluded from this repository to maintain a clean codebase.*
